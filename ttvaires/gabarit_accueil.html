Réglage du bouton (une seule fois par téléphone)

Le bouton demande à GitHub de lancer la mise à jour. Il lui faut une « clé » (jeton) que tu crées une fois, et qui reste uniquement sur ce téléphone :

  1. Ouvre github.com → Fine-grained tokens → Generate new token (connecté avec ton compte GitHub).
  2. Nom : « Vaires téléphone » ; expiration : 1 an ; Repository access : Only select repositories → .
  3. Permissions → Repository permissions → Actions : Read and write. Rien d'autre.
  4. « Generate token », copie le jeton (il commence par github_pat_) et colle-le ici :

Sans réglage, depuis l'appli ou le site GitHub : Actions → Mise à jour du site → Run workflow.
