DOSSIER IMPORT : listes de licenciés enregistrées depuis ton navigateur
=======================================================================

Quand pingpocket.fr bloque les requêtes de l'outil (protection anti-robot),
la liste complète des licenciés (non réinscrits, licences loisir, catégories)
peut être fournie à la main. L'outil lit alors les pages déposées ici.
Rien n'est contourné : tu consultes le site normalement, comme d'habitude.

1. Ouvre dans ton navigateur (Chrome, Edge ou Firefox) les trois listes du club :

   par catégorie d'âge (indispensable) :
   https://www.pingpocket.fr/?page=app%2Ffftt%2Fclubs%2F08770250%2Flicencies%3FSORT%3DCATEGORY

   par licences à jour (indispensable : sépare les non réinscrits) :
   https://www.pingpocket.fr/?page=app%2Ffftt%2Fclubs%2F08770250%2Flicencies%3FSORT%3DLICENCE_STATE

   par classement officiel (facultatif) :
   https://www.pingpocket.fr/?page=app%2Ffftt%2Fclubs%2F08770250%2Flicencies%3FSORT%3DOFFICIAL_RANK

   Si un lien n'affiche pas la liste : ouvre https://www.pingpocket.fr/?page=app/fftt/clubs/08770250
   puis va dans « Licenciés » et choisis le classement voulu.

2. Quand la liste est affichée : Ctrl+S, type « Page Web, complète »
   (ou « Page Web, fichier unique .mhtml »), et enregistre dans CE dossier.
   Pas « HTML uniquement » : la liste n'y figure pas.
   Une page par liste, ou une seule page après avoir ouvert les trois listes
   à la suite : les deux fonctionnent. Le nom du fichier n'a pas d'importance.

3. Relance lancer.bat : option 3 pour l'effectif de Vaires, option 4 pour le
   classement virtuel (qui a besoin de la liste pour inclure tous les joueurs).

La page la plus récente l'emporte : réenregistre les listes de temps en temps
(par exemple avant chaque journée) pour voir les nouvelles réinscriptions.
Si pingpocket répond de nouveau à l'outil, sa liste du jour est utilisée.

Ça marche aussi pour les clubs adverses (option 1) : remplace 08770250 par
le numéro du club dans les liens ci-dessus (indiqué en haut de sa fiche).

Ces pages contiennent des données personnelles (dont des mineurs) : elles ne
sont jamais publiées en clair (dossier exclu du dépôt). Seule une copie chiffrée
avec le mot de passe du club part sur GitHub pour la mise à jour du site (option 7).


CLASSEMENTS DES POULES (image classements_poules.png, avec l'option 1, 5 ou 9)
==========================================================================

Le logo du club en haut à gauche est fourni avec l'outil. Pour en mettre un
autre : logo_club.png dans CE dossier (sinon logo_gauche.png). Un fond
transparent (png) est conseillé.


RÉCAPITULATIF DE LA JOURNÉE (image recap_J3.png, avec l'option 2, 5 ou 9)
==========================================================================

L'image reprend le modèle du club (Excalidraw) ; la place de la photo est en haut.
Pour que l'outil la complète tout seul, dépose dans CE dossier :

- photo_J3.jpg : la photo de la journée 3 (photo_J4.jpg pour la J4...). jpg, png
  ou webp, de n'importe quelle taille : elle est recadrée pour remplir la place
  (742 x 449, en gardant le haut de la photo). Sans photo, la place reste libre
  pour la coller soi-même.
- logo_gauche.png et logo_droite.png (une fois pour toutes) : les logos posés
  dans les coins haut gauche et haut droit de la photo. Un fond transparent
  (png) est conseillé.
- surnoms.txt (facultatif) : le nom affiché d'un joueur, une ligne par joueur,
  par exemple :
      GUITTON Marc = Marc G
      LE CERF Christian = Christian LC
  Sans surnom : le prénom, suivi des initiales du nom si deux joueurs de l'image
  ont le même prénom (Jérôme D, Jérôme L). Mise à jour lancée depuis le site sans
  passer par le PC : mettre les mêmes lignes dans le secret GitHub SURNOMS (voir
  PUBLICATION.md).

Puis option 9 (30 secondes, sans rien télécharger) : l'image est refaite avec la
photo. Ces fichiers sont envoyés au site avec les autres (chiffrés ; une grosse
photo est réduite), pour que l'image en ligne soit la même.
